# Passkit Plugin

This plugin allows you to add passes to the iOS Wallet app (previously known as Passbook).

### Platforms:
iOS 8+

### Make Passes Easy:
- [passkit](https://create.passkit.com)
- [passslot](https://www.passslot.com)

### Functions:

#### passkit.add(filePath, listener)
file (path) — path for .pkpass file
listener (function) — returns event.status values:
- "showing"
- "finished"
